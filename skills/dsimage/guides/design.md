# design：只有产品，没模板，从零设计一套

目标是把用户脑子里的需求问出来，落成一个 smart 模板，然后按 `smart.md` 出图。模板留在库里，下次同类品直接用。

## 1. 先看品

打开产品图。说出它是什么、卖给谁、靠什么打动人（好看 / 解决痛点 / 情感价值），这决定套图顺序。有多张图先定白图。

## 2. 问需求

一次问完，用户没答的先按括号里的默认值做并列出来，不要反复追问：

| 问 | 默认 |
|---|---|
| 平台（亚马逊 / 独立站 / 淘宝天猫 / 小红书 / 1688 报价…） | 独立站 |
| 图内文字语言 | 跟用户说话的语言 |
| 图内要不要文字；要的话谁写卖点（用户给 / 你拟） | 少量文字，你拟，用户改 |
| 风格（干净白底 / 高级暗调 / 生活场景 / 信息图…），有没有参考图 | 干净商业风 |
| 几张，每张是什么（主图 / 卖点 / 细节 / 场景 / 尺寸 / 模特 / 对比 / 包装…） | 5–9 张，见下 |
| 画幅（1:1 / 4:5 / 2:3 / 16:9）、分辨率（1k/2k/4k） | 1:1，1k |
| 交付：固定像素？体积上限？格式？ | 不限 |
| 一品多色怎么办 | 锁一个主色，配色只出一张合集 |

亚马逊主图：纯白底、无文字。小红书：4:5 或 3:4、真实感、少排版。1688 / 报价单：白底 + 规格文字。

常用 7 张骨架：H1 主图 · H2 核心卖点 · H3 材质细节 · H4 结构/功能 · H5 使用场景 · H6 尺寸/规格 · H7 包装/保障。按品增删。

## 3. 建 smart 模板

```bash
python scripts/dsimage.py template init <模板名> --blank --slots 7 --mode smart --category "<品类>" --language "<语言>"
```

填 `templates/<模板名>/template.json`：

- `style`：一段英文风格锁：背景色（hex）、光、色板、字体感觉、图标风格、留白、禁止项。写完整，每条 prompt 都要原样带。
- `text_policy`：文字语言、长度、位置、禁止事项。
- `output`：画幅、分辨率、格式，交付要求写进 `deliver`（`width/height` 或 `max_px`，`max_bytes`）。
- 每槽 `purpose` + `brief`：这一页要表达什么、放什么信息、产品占比大概多少。拍法翻 `knowledge/shots.md`。
- 用户有参考图，可拷进模板夹填 `example`（smart 里只当版式参考）。

```bash
python scripts/dsimage.py template check <模板名>
```

## 4. 出图

转 `smart.md`：`init` → `run` 得 brief → 写 prompts.json → `run --only` 先出一个 → 看 → 改 → 铺。

## 5. 收口

用户满意后问：这套要不要冻成 replace 模板（`template freeze`），以后同类品直接换货。
