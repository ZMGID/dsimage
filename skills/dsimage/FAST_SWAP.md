# 快速换货（Agent 按此执行）

> 用户说「快速换货 / 同类快换 / 快速替换」，或给了样板套图 + 很多型号、只要换商品时读本文件。
> 这不是第三种模板。锁的还是母版（`lock=master`）。
> **原型靠 Agent 看图**：选定那一张商品白图，按模板/母版出一套，不行就改、再出，直到用户点头。
> **点头之后**：其余编号不写 Prompt、不派品工人；每品仍是一张白图 + 各槽母版，脚本填 jobs 出图。
> 适合：同一类货、版式不动、字不改、数量多。不适合：要重画、要改货号/价格、品类差很远、没有齐套母版。

默认提示词只写在 `scripts/swap_fast.py` 的 `DEFAULT_PROMPT`。各槽共用这一句，差别在图（该槽母版 + 该品那张白图），不要给 H1–H9 各写一版。

```text
Replace only the product in the first image with the product from the second image. Keep layout, text, icons, and background unchanged.
```

甲方默认：**一品一张白图**，文件名不带颜色、也不带正背面。母版页自己已经是主图/背面/场景；换货时每槽都用这一张产品图。

---

## 步骤

每步做完再进下一步。原型没点头不要铺开。

### 1. 对齐材料

要有两样：一套母版页（样板主图 / 已登记 `lock=master` 模板），加上要换进去的产品图。源目录按 SKILL「甲方文件夹」。

对用户确认下面几件事（一次说完）。**抽检默认关**，不说就不停。尺寸、档位、交付**不要抄技能里的数字**，由你按本轮原话 + 母版像素 + 模板/甲方 `generation` 填进命令。

1. 母版和新品是同一类（书包换书包）。不是就停下，不要硬换。
2. 图上的字一律不动。要改货号/价格就改走 SKILL「换货」长 Prompt，不要用本文件。
3. 你填这些参数（用户没说的项用模板/甲方；都没有才用脚本兜底）：
   - `--resolution`：`1k` / `2k` / `4k`
   - 生图比例跟母版/目标画布走，禁止变形压
   - 交付：`--output-size <宽x高>` 或 `--max-px` / `--max-bytes`；没说就不压
4. 铺开时默认一口气出完。要每隔 N 个品停，填 `--inspect-every <N>`。

库里没有 `lock=master` 模板时，用用户给的样板文件夹 `--masters`，不要改走默认电商模板、不要按规则重画。

**完成：用户确认同类、冻字、生图档、交付（或不压）、抽检（或默认不停）。**

### 2. Agent 看图做原型

跑 `match_pack.py --query "<用户原话>"`，把 stdout 给用户看。第 1 名若不是母版，仍用 `--masters` 或用户点的母版模板。

**选图是你的事，不要交给脚本猜文件名。** 打开母版每一页，打开甲方夹，看画面：选定试跑品、选定那一张白图（一品基本只有一张）。对不上的编号或图停下问。

把白图放到成图根 `{编号}/` 里。可以先 `--init` 建批次和文件夹，但拷进去的图你必须打开看过；认不对就换掉再出图。

```bash
python scripts/queue_pack.py --init --fast --source "<甲方大文件夹>" --masters "<样板文件夹>" --category "<品类>"
# 已有 lock=master 模板时用 --template
# 按本轮填： --resolution <1k|2k|4k> ；--output-size <宽x高> 或 --max-px / --max-bytes
```

确认该编号夹里就是你选的那张白图之后，出**一整套**（H1 到最后一槽都要，不要只出主图）：

```bash
python scripts/queue_pack.py --queue "<成图根>/_prompts/批次.json" --pilot "<编号>" --run
```

有生图 API 才 `--run`。没有 API、走宿主生图：jobs 用该槽母版 + 你选的那张白图，**沿用 `swap_prompt.txt`**。单品槽位同时最多 4 路。

一品一张白图时，每个槽都用这一张，不要因为没有「背面」文件名就跳过背面页。

**完成：试跑套图路径已给用户。**

### 3. 改到点头（还不行就继续改）

把试跑成图给用户。不满意或某处不行：改那一句提示词、换一张白图、或只改某一槽，再生成。还不行就接着改。不要这一步没点头就铺开。

- 改共用句：`--queue ... --set-prompt "新的一句"`，再 `--pilot <编号> --run`（不要 `--skip-existing`）。
- 只改某一槽：`--set-slot-prompt H5 "该槽的一句"`，再重出该试跑品。
- 换白图：换成你新选的那张，再重出。

**完成：用户说这套可以了。**

### 4. 铺开（不写 Prompt）

点头之后才铺。其余编号同样 **Agent 看图选白图** 放进各 `{编号}/`，不要让脚本靠文件名猜完就出。选好之后：

```bash
python scripts/queue_pack.py --queue "<成图根>/_prompts/批次.json" --blast --run --skip-existing
```

`--blast` 用已锁提示词给剩余编号填 jobs（每槽：母版 + 该品那张白图）。不要 `--next` 派品工人，不要给每个编号写 Prompt。

`inspect_every` 大于 0：`--run` 一次只出 N 个品，看过再继续。为 0：一口气出完。

失败槽位改句后只重跑失败的。某一槽系统性翻车 → `--set-slot-prompt` 再铺（已成功的页会跳过）。

**完成：`--next` 显示全部完成，或只剩 skip/empty。**

### 5. 交付压图（有要求才做）

批次.json 里有 `deliver` 才跑。没有就跳过。

```bash
python scripts/queue_pack.py --queue "<成图根>/_prompts/批次.json" --deliver
```

只缩小、不变形。只压 `h1.png`… 套图，不要压白图。

**完成：压完列出路径，或本步跳过。**

### 6. 问要不要检查

问一句要不要抽查。已经按波看过的，问一句还要不要再看。用户说不用则结束。

要检查：对照母版 + 该品白图，看产品是否换成新货、字和图标有没有被改、有没有坏图。问题记在一起再改。

整批收口一次。问要不要把样板登记成 `lock=master` 模板；用户说要 → `CREATE_TEMPLATE.md`。

**完成：用户已答要不要检查；有问题已记下来或已改完。**
